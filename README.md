# آزمون‌ساز

سایتی فارسی و راست‌چین که در آن هر کس می‌تواند آزمون چندگزینه‌ای بسازد، لینکش را به دیگران بدهد و نتایج را ببیند.

- بدون ثبت‌نام: سازنده یک «لینک مدیریت» محرمانه می‌گیرد که با آن نتایج را می‌بیند.
- نمره‌دهی در سرور انجام می‌شود، پس پاسخ‌های درست برای شرکت‌کننده‌ها پیش از ثبت دیده نمی‌شود.
- فرانت‌اند ساده (HTML/CSS/JS بدون ابزار ساخت) روی GitHub Pages، پایگاه‌داده روی Supabase (پلن رایگان).

## راه‌اندازی

### ۱) پایگاه‌داده (Supabase)
1. در [supabase.com](https://supabase.com) یک پروژه‌ی جدید بسازید.
2. از منوی **SQL Editor** محتوای فایل `supabase/schema.sql` را اجرا کنید.
3. از **Project Settings → API** مقدار `Project URL` و کلید `anon public` را بردارید.
4. این دو را در `config.js` بگذارید. کلید anon عمومی است و گذاشتنش در کد مشکلی ندارد (دسترسی مستقیم به جدول‌ها بسته است و فقط تابع‌های `schema.sql` قابل‌استفاده‌اند).

### ۲) انتشار روی GitHub Pages
1. یک ریپوی جدید در GitHub بسازید و کد را در شاخه‌ی `main` بفرستید:
   ```bash
   git remote add origin https://github.com/<نام-کاربری>/<نام-ریپو>.git
   git push -u origin main
   ```
2. در ریپو: **Settings → Pages → Source** را روی **GitHub Actions** بگذارید.
3. با هر push روی `main`، سایت خودکار منتشر می‌شود (`.github/workflows/pages.yml`).

آدرس سایت: `https://<نام-کاربری>.github.io/<نام-ریپو>/`

## اجرای محلی
```bash
python3 -m http.server 8000
# سپس http://localhost:8000
```

## ساختار
| فایل | کار |
|---|---|
| `index.html`, `style.css`, `app.js` | رابط کاربری (ساخت آزمون، شرکت در آزمون، نتایج) |
| `config.js` | آدرس و کلید Supabase |
| `supabase/schema.sql` | جدول‌ها و تابع‌های امن پایگاه‌داده |

## نکات
- لینک‌ها به شکل `#/q/<شناسه>` (شرکت در آزمون) و `#/m/<شناسه>/<کلید>` (مدیریت) هستند. کلید مدیریت در بخش `#` می‌آید و به هیچ سروری فرستاده نمی‌شود، جز برای تأیید در تابع `get_results`.
- گم شدن لینک مدیریت قابل بازیابی نیست. این سازوکار عمداً ساده نگه داشته شده؛ اگر بعداً حساب کاربری خواستید، می‌توان Supabase Auth را اضافه کرد.
- شرکت چندباره‌ی یک نفر محدود نشده است. برای محدودیت جدی‌تر باید ورود کاربر اضافه شود.
