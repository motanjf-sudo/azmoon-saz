# آزمون‌ساز

سایتی فارسی و راست‌چین که در آن هر کس می‌تواند آزمون بسازد، لینکش را به دیگران بدهد و نتایج را ببیند.

- **سه مدل سؤال:** چندگزینه‌ای (۲ تا ۸ گزینه)، درست/نادرست، جای خالی (انتخاب پاسخ از یک باکس بازشونده). مدل «تشریحی» بعداً اضافه می‌شود.
- هر آزمون می‌تواند ترکیبی از مدل‌ها باشد.
- بدون ثبت‌نام: سازنده یک «لینک مدیریت» محرمانه می‌گیرد که با آن نتایج و آمار هر سؤال را می‌بیند.
- نمره‌دهی در سرور انجام می‌شود، پس پاسخ‌های درست پیش از ثبت دیده نمی‌شود.
- فرانت‌اند ساده (HTML/CSS/JS بدون ابزار ساخت) روی GitHub Pages، پایگاه‌داده روی Supabase (پلن رایگان).

## راه‌اندازی

### ۱) پایگاه‌داده (Supabase)
1. در [supabase.com](https://supabase.com) یک پروژه‌ی جدید بسازید.
2. از منوی **SQL Editor** محتوای فایل `supabase/schema.sql` را اجرا کنید. اجرای دوباره‌ی آن بی‌خطر است و داده‌ها پاک نمی‌شوند. بعد از هر به‌روزرسانی پروژه، یک بار دوباره اجرایش کنید.
3. از **Project Settings → API Keys** مقدار `Project URL` و کلید publishable (یا anon) را بردارید.
4. این دو را در `config.js` بگذارید. این کلید عمومی است و گذاشتنش در کد مشکلی ندارد (دسترسی مستقیم به جدول‌ها بسته است و فقط تابع‌های `schema.sql` قابل‌استفاده‌اند).

### ۲) انتشار روی GitHub Pages
1. کد را در شاخه‌ی `main` یک ریپوی GitHub بگذارید.
2. در ریپو: **Settings → Pages → Source** را روی **GitHub Actions** بگذارید.
3. با هر تغییر روی `main`، سایت خودکار منتشر می‌شود (`.github/workflows/pages.yml`).

## اجرای محلی
```bash
python3 -m http.server 8000
# سپس http://localhost:8000
```

## ساختار
| فایل | کار |
|---|---|
| `index.html` | صفحه‌ی اصلی، همه‌ی استایل‌ها و جلوه‌های بصری |
| `app.js` | منطق برنامه: انتخاب مدل، ساخت آزمون، شرکت در آزمون، نتایج |
| `config.js` | آدرس و کلید Supabase |
| `supabase/schema.sql` | جدول‌ها و تابع‌های امن پایگاه‌داده |

## مسیرها
- `#/` صفحه‌ی اصلی
- `#/create` انتخاب مدل آزمون
- `#/create/<mcq|tf|blank>` ساخت آزمون
- `#/q/<شناسه>` شرکت در آزمون
- `#/m/<شناسه>/<کلید>` مدیریت و نتایج

## نکات
- کلید مدیریت در بخش `#` لینک می‌آید و به هیچ سروری فرستاده نمی‌شود، جز برای تأیید در تابع `get_results`.
- گم شدن لینک مدیریت قابل بازیابی نیست. اگر بعداً حساب کاربری خواستید، می‌توان Supabase Auth را اضافه کرد.
- شرکت چندباره‌ی یک نفر محدود نشده است.
- پیش‌نویس آزمون در مرورگر ذخیره می‌شود تا با بستن ناگهانی صفحه از بین نرود.
- برای افزودن مدل «تشریحی»: نوع `essay` را در `app.js` (جدول `TYPES`) و تابع‌های `create_quiz` و `submit_quiz` فعال کنید.
